# Product

## Register

brand

## Users

Chris reviews the brand assignment. Jerio presents and revises it. The landing-page exploration serves a different journey: a property or hospitality client discovering Meta Pacific's work and deciding whether to start a project.

## Product Purpose

Keep the 13-task assignment, design library and commercial landing page distinct. Each task explains a decision and exports independently. The landing page demonstrates the identity as a real business surface, with three selectable logo-led treatments.

## Brand Personality

Cinematic, direct, curious. Show real locations and useful choices. Keep copy specific to film, photography and spatial experiences.

## Anti-references

Generic side-stripe callouts, repetitive cards, beige presentation, synthetic images, decorative watermarks, visible inspiration archives, confusing assignment toolbars on the business page, and large lettering colliding with photographs. These are explicit user corrections, not inferred preferences.

## Design Principles

Separate the reviewer journey from the prospective-client journey. Give each page one clear next step. The exploration has one compact return link and an identity selector; task navigation and PDF controls stay in the assignment. Carry the chosen identity through type, layout and color, not just the logo. Keep the actual work prominent. Use plain explanation instead of packaged callouts.

## Accessibility & Inclusion

Motion is required across all assignment pages, not only the homepage. Give each task a visual interaction related to its content. Keep task navigation, reading, downloads and quotation editing usable throughout. Preserve the existing print deliverables as static documents.

Preserve readable contrast, keyboard navigation, native controls, clear focus and narrow-screen layouts. Motion starts automatically without an enable button; reduced-motion preferences receive a quiet alternative. Large original contour-lips artwork, moving display type and photographic cuts lead the web openings. Supporting photographic sequences remain in the work. All motion starts automatically with a footer pause control. No emoji-capable navigation symbols or default decorative stickers. Keep text steady and avoid flashing. Never hide essential content behind animation.
